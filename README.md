### Indra Shell Themes

A fork of the existing Breeze shell themes but with more minimal and consistent background fills and opacity. It comes with 4 variants:

* **Indra:** 60% background fill opacity with subtle specular highlights.
* **Indra Clean:** 60% background opacity with specular highlights removed.
* **Indra Shuniya:** *(Sanskrit for void / zero)* 0% background opacity, fully transparent. Built to let your desktop blur effect control brightness and contrast evenly.
* **Indra Shuniya Clean:** 0% background opacity with all boundary strokes removed.

##### Nirguna
<img width="1920" height="1080" alt="Nirguna Stock" src="https://github.com/user-attachments/assets/54e2562a-67f0-4772-8f0f-90bdff61b169" />

**Nirguna** *(Sanskrit for "attributeless")* is a balanced dark base tuned specifically for seamless dynamic tinting.

##### With Tint
<img width="1920" height="1080" alt="Nirguna Tinted" src="https://github.com/user-attachments/assets/e006cabf-be3d-4628-8b52-c920e49a245a" />

How to set up dynamic wallpaper tinting:
1. Open **System Settings → Colors & Themes → Colors**.
2. Select **Nirguna**, click the **Edit (Pencil)** icon, and go to **Options**.
3. Check **Tint colors with accent color** and save.
4. Back in the Colors header, choose **Accent color from wallpaper** and dial the tint strength slider to your preference.

### Resources you should Check out:

A few things that made KDE really beautiful for me after switching from Windows:

- **Application Style:** [Darkly](https://github.com/Bali10050/Darkly) — Clean, modern, and light on system overhead.
- **Blur Shader:** [kwin-effects-glass](https://github.com/4v3ngR/kwin-effects-glass) — Far cleaner luminance gradients and depth than the stock KWin blur.
- **Cursor:** [Bibata Cursor](https://github.com/ful1e5/Bibata_Cursor) — Sharp and minimal.
- **Typography:** [Inter](https://rsms.me/inter/) for interface labels and [JetBrains Mono](https://www.jetbrains.com/lp/mono/) for code and terminal blocks, set at 9pt (calibrated for 1080p on a 24-inch monitor).
- **Liquid Glass Widgets:** [jaxparrow07](https://github.com/jaxparrow07/liquidglass-kde-widgets) — The widgets being used in the screenshot! (Mine are still a fork, making them use system-wide blur instead of their custom shader).
